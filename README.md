# The Joke the Reviewer Laughs At

A one-line joke about working beside AI coding agents, written by `main.py`
to `/output/entry.txt` for the
[make.fun competition](https://make.fun/c/the-joke-the-reviewer-laughs-at-20261121-0329).

## The joke

> The agent refactored my code so cleanly the bug now has perfect separation of concerns.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The program writes exactly one line of UTF-8 text (1–280 characters) and
needs no network.

## Why this joke

The judge weighs, in order: on-subject, surprise, truth from the diff,
economy, freshness. This one is built for the reviewer reading the diff:
the agent's refactor is beautiful, the bug survives it — elegantly
organised. One line, no explanation, nothing wasted.
